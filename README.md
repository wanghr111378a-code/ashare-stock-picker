# ashare-stock-picker
A股三大独立策略智能选股器
A股智能独立选股器

项目介绍

一款面向安卓手机的A股智能选股应用，三个策略独立运行，互不干扰。

三大独立策略

1. 北京炒家策略：独立股票池、筛选规则、评分和选股结果。
2. 退学炒股策略：独立股票池、筛选规则、评分和选股结果。
3. 炒股养家策略：独立股票池、筛选规则、评分和选股结果。

以上策略为公开交易理念的量化近似，不代表交易者的真实私有公式。

V1.0 开发目标

- 安卓手机独立使用
- 三个策略完全独立
- 独立股票池和选股榜单
- 独立买卖计划与历史记录
- 本地数据保存
- 支持行情数据接入
- 支持生成安卓 APK

数据原则

行情必须注明真实来源和更新时间。行情接口不可用时明确提示，不得伪造实时行情。

风险提示

选股结果仅供研究参考，不构成投资建议。历史回测不代表未来收益。
